LNbits - Le couteau suisse de l'infrastructure

5. LNbits

Avec les services réseau configurés via LIT, ce chapitre configure LNbits, la couche de gestion des fonds de l'infrastructure. Nous verrons comment initialiser le service, créer des portefeuilles, gérer les extensions et effectuer des sauvegardes.

LNbits est une solution de portefeuille et de système de comptes qui s'exécute sur un nœud LND, permettant de segmenter les fonds et d'activer des fonctionnalités étendues via des extensions. C'est le moteur qui traite les transactions des autres services. On peut dire que c'est le couteau suisse Lightning. Vous pouvez en savoir plus sur le site officiel de LNbits.

5.1 Initialisation de LNbits

La première chose à faire est d'accéder au site que nous avons configuré dans le chapitre NPM : https://lnbits.cashu4community.xyz. Comme c'est la première fois, une page s'affiche pour créer le compte du superutilisateur, qui dispose des privilèges maximaux. Il suffit de saisir un nom d'utilisateur et le mot de passe (deux fois).

Image 1 : Création du compte superutilisateur dans LNbits.

  1. Nous saisissons le nom d'utilisateur.
  2. Nous saisissons le mot de passe du compte deux fois. Un mot de passe d'au moins 12 caractères, avec des majuscules, des minuscules et des caractères spéciaux est recommandé.
  3. Nous appuyons sur LOGIN pour créer le compte.

Image 2 : Page de connexion.

  1. Nous saisissons l'utilisateur créé à l'étape précédente.
  2. Nous faisons de même avec le mot de passe.
  3. Nous cliquons sur LOGIN.

Après la connexion, la page de paramètres de LNbits se charge. Nous pouvons naviguer entre différentes sections ; ce chapitre couvrira les plus importantes.

Image 3 : Page de paramètres de LNbits.

5.1.1 Paramètres de Financement (Backend Lightning de LNbits)

Image 4 : Page de Paramètres (Financement).

  1. Le solde total des comptes LNbits et le solde du nœud sont affichés.
  2. Le backend de LNbits pour l'infrastructure est le Lightning Network Daemon (LND). Cette configuration est définie dans le fichier .env situé dans le répertoire app-data/lnbits/.

5.1.2 Paramètres de Paiements

Image 5 : Page de Paramètres (Paiements).

  1. Nous sélectionnons les devises fiduciaires qui seront disponibles dans LNbits.
  2. Nous sélectionnons la devise par défaut qui affichera la valeur des sats dans le compte.
  3. Nous sélectionnons la commission qui sera prélevée sur les transactions sortantes (uniquement si l'on souhaite réaliser un petit bénéfice).
  4. Si nous assignons une valeur à la commission par transaction, nous devons ajouter l'ID du portefeuille qui recevra les commissions. Les étapes suivantes expliquent comment obtenir l'ID du portefeuille.
  5. Nous désactivons la commission pour les transactions internes.
Note : Après avoir effectué les modifications, nous devons cliquer sur SAVE puis sur RESTART SERVER ; sinon les changements ne seront pas appliqués.

5.1.3 Paramètres des Extensions

Depuis cette page, nous pouvons sélectionner les extensions qui se chargeront par défaut, aussi bien dans les sections administratives que dans celles des utilisateurs standard (sans privilèges).

Image 6 : Page de Paramètres (Extensions).

  1. Nous sélectionnons les extensions pour les utilisateurs administrateurs.
  2. Nous sélectionnons les extensions pour les autres utilisateurs.
Note : Seules les extensions activées apparaîtront ici. Pour ajouter d'autres extensions, il faut aller à la section Extensions dans le menu d'options à gauche de la page.

5.2 Création d'un portefeuille pour les commissions de transaction

Lorsque nous nous connectons à LNbits, un portefeuille par défaut est créé. Nous allons le renommer et l'utiliser pour recevoir les commissions de transaction.

Image 7 : Renommer le portefeuille par défaut.

  1. Nous sélectionnons le portefeuille.
  2. Nous cliquons sur Wallet Config dans le panneau de droite.
  3. Nous changeons le nom du portefeuille en Service fees.
  4. Nous cliquons sur le bouton UPDATE NAME.

Nous avons ainsi renommé le portefeuille pour identifier clairement son objectif.

Image 8 : Obtention de l'ID du portefeuille Service fees.

  1. Nous cliquons sur Node URL, API Key and API docs dans le panneau de droite.
  2. Nous copions le champ Wallet ID.

Ensuite, nous allons dans les paramètres de Paiements (comme vu à la section 5.1.2) et nous collons l'ID du portefeuille dans le champ du point 12.

5.3 Extensions de LNbits

Les extensions de LNbits sont des plugins qui ajoutent des fonctionnalités spécifiques. Elles permettent de créer des portefeuilles avec des règles personnalisées (limites, expiration), d'intégrer des systèmes de paiement, du commerce électronique, des billets, des jeux, du financement participatif ou des mécanismes comme LNURL. Étant modulaires, nous n'installons que ce dont nous avons besoin, sans alourdir le système.

Voyons maintenant comment ajouter et supprimer des extensions.

Image 9 : Extensions.

  1. Nous cliquons sur la vue des extensions pour lister les extensions disponibles.

Par défaut, seules quelques extensions sont disponibles pour les utilisateurs, il faut donc installer les autres. L'étape suivante explique comment les installer.

Image 10 : Sélection de l'extension à installer.

  1. Nous sélectionnons l'extension à installer.

Dans l'exemple, nous sélectionnons l'extension LndHub, très utile si nous souhaitons utiliser des portefeuilles comme BlueWallet ou Zeus pour gérer les fonds, payer et recevoir des paiements sur notre compte.

Image 11 : Sélectionner la version à installer.

  1. Nous déroulons la liste des versions.
  2. Nous sélectionnons celle disponible en cliquant sur INSTALL.

Après quelques secondes, l'extension apparaîtra dans la vue des extensions installées.

Image 12 : Extensions installées.

Pour commencer, il est recommandé d'installer les extensions LNURLp, Withdraw Links et LndHub. Ensuite, nous pouvons aller dans les paramètres des Extensions et les activer pour tous les utilisateurs, comme vu à la section 5.1.3, point 15.

5.4 Autres options

Dans la vue principale, nous pouvons trouver d'autres options qui nous permettront d'avoir un contrôle plus large de ce qui se passe dans notre instance LNbits.

Image 13 : Options Avancées d'Administration de l'instance LNbits.

  1. Paramètres de LNbits.
  2. Administration des utilisateurs et des portefeuilles.
  3. Requêtes à l'API de LNbits en temps réel.
  4. Visualisation des paiements effectués, avec des informations utiles pour effectuer des recherches.
  5. Administration des extensions.

5.5 Sauvegarde de la base de données et des configurations de LNbits

LNbits permet d'effectuer une sauvegarde de la base de données, des extensions et des journaux depuis l'interface web. Pour une sauvegarde manuelle, il suffit d'aller dans les paramètres et de cliquer sur DOWNLOAD DATABASE BACKUP comme indiqué dans l'image suivante.
