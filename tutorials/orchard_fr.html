Administration du Mint Cashu avec Orchard

7. Orchard

Avec le Mint Cashu opérationnel, ce chapitre configure Orchard, l'outil web qui nous permet d'administrer le Mint de façon visuelle. Orchard est en développement actif, c'est pourquoi nous recommandons d'être prudents dans son utilisation.

7.1 Initialisation d'Orchard

Nous accédons à Orchard via https://orchard.cashu4community.xyz (chaque communauté y accédera via son propre domaine). La première chose que nous voyons est l'écran d'initialisation, qui nous demande la SETUP_KEY. Cette clé a été générée lors de la configuration de l'infrastructure et nous avons dû la sauvegarder. Si nous ne la trouvons pas, nous pouvons la consulter dans le fichier app-data/orchard/.env.

  1. Nous saisissons la clé SETUP_KEY générée lors de la configuration de l'infrastructure. Si nous ne l'avons pas sauvegardée, nous pouvons la trouver dans le fichier .env à l'emplacement app-data/orchard/.env.
  2. Nous saisissons le nom d'utilisateur (peut être admin, orchard ou selon notre préférence).
  3. Nous saisissons un mot de passe et le confirmons.
  4. Nous cliquons sur le bouton Start pour enregistrer les modifications.

7.2 Tableau de bord

Orchard permet d'afficher des informations sur le nœud Bitcoin si nous en avons un installé, sur le nœud Lightning et sur le Mint Cashu. Les sections nœud Bitcoin et nœud Lightning sont uniquement informatives, il n'y a pas grand-chose à faire là-dedans, c'est pourquoi nous nous concentrerons sur le Mint Cashu.

  1. Les informations du Mint sont affichées : son nom, son URL, sa description et d'autres données.
  2. Les NUTs actifs dans le Mint Cashu sont affichés.
  3. Les données liées aux Keysets sont affichées.
  4. Dans la vue Activités sont affichés le nombre d'opérations, le nombre d'opérations Melt et Mint, le pourcentage d'opérations complétées, entre autres données.

7.3 Section Info

Dans la section Info, nous pouvons mettre à jour toutes les informations du Mint concernant les coordonnées de contact. Tout peut être mis à jour depuis cette vue.

  1. Après avoir mis à jour les données du Mint, nous procédons à leur enregistrement.

Toutes ces informations peuvent également être éditées dans le fichier app-data/cashu/.env dans la section Mint Information :

# Mint information
MINT_INFO_NAME="Cashu4CS"
MINT_INFO_DESCRIPTION="The short mint description"
MINT_INFO_DESCRIPTION_LONG="A Cashu4Community Mint for educational purpose"
MINT_INFO_CONTACT=[["email","contact@cashu4community.xyz"], ["twitter","@cashu4community"]]
MINT_INFO_MOTD="Message to users"
MINT_INFO_ICON_URL="https://cashu4community.xyz/images/icons/cashu4community_logo_transparente.png"
MINT_INFO_URLS=["https://mint.cashu4community.xyz"]
MINT_INFO_TOS_URL="https://mint.host/tos"

7.4 Section Config

Actuellement, la section Config n'est pas fonctionnelle, et tout ce qui s'y affiche est informatif : le maximum et le minimum d'une opération de mint ou melt, activer ou désactiver Redis, entre autres options. Ces options sont également présentes dans le fichier .env. Selon le développeur, ces fonctions via RPC ne sont pas encore implémentées.

7.5 Section Keysets

Depuis cette section, nous pouvons configurer un nouveau keyset sans avoir à interagir avec la ligne de commande. Elle n'a qu'une limitation : pour le moment, elle ne fonctionne qu'avec les keysets version v1 ; la dernière mise à jour de Nutshell incorpore la version v2.

  1. Si nous voulons ajouter un nouveau Keyset, nous pouvons le faire ici.
  2. Liste des Keysets existants dans le Mint.
  3. Après avoir sélectionné la commission à utiliser, nous sélectionnons la version du keyset. Pour le moment, Orchard ne supporte que la v1.
Note : Si vous utilisez la version 0.20 de Nutshell, il est recommandé de générer les nouveaux Keysets via mint-cli (cela est visible dans la documentation du Mint Cashu).

7.6 Section Database

Cette section affiche les informations stockées dans la base de données, comme les opérations de Mint et Melt. Des sauvegardes de la base de données peuvent être effectuées, parmi d'autres options de visualisation.

  1. En cliquant sur le bouton Create Backup, nous pouvons effectuer une sauvegarde de la base de données.
