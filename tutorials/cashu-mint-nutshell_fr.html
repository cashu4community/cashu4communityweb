Mint Cashu (Nutshell)

6. Mint Cashu (Nutshell)

Avec LNbits configuré comme backend de paiements, ce chapitre configure le Mint Cashu. Le Mint est le composant principal de l'infrastructure Cashu : il garde en dépôt les bitcoins des utilisateurs et, en échange, émet des tokens (« coupons numériques ») représentant cette valeur. À la fin, le Mint sera prêt à recevoir des dépôts et à émettre des tokens aussi bien en sats qu'en USD.

6.1 Configuration du backend Lightning (LNbits)

Nous allons configurer un nouveau portefeuille dans LNbits qui servira de dépôt principal pour les fonds des utilisateurs du Mint. Ce portefeuille sera chargé de recevoir les sats lorsqu'un utilisateur souhaite déposer des fonds dans le Mint, et d'envoyer les sats lorsqu'un utilisateur souhaite les retirer.

Nous allons sur le compte créé dans le chapitre LNbits, nous nous connectons et créons le portefeuille. L'image suivante montre le processus.

Image 1 : Création du portefeuille pour les dépôts du Mint.

  1. Nous cliquons sur Add a new wallet.
  2. Une fenêtre apparaît où nous saisissons le nom du portefeuille ; nous mettons Cashu Mint. Ce peut être n'importe quel nom, l'important est de savoir à quoi ce portefeuille sera destiné.
  3. Nous ajoutons le portefeuille.

Après sa création, nous devons obtenir la clé API qui nous permettra de recevoir des paiements et de payer des factures.

De la même manière qu'au chapitre précédent (LNbits) où nous avons cherché l'ID du portefeuille pour les commissions de transaction, nous cherchons ici la clé Admin key.

Image 2 : Clé Admin key pour effectuer et recevoir des paiements dans le Mint Cashu.

  1. Nous sélectionnons la clé Admin key.
  2. Nous copions la clé.

Depuis le terminal, nous nous déplaçons vers le répertoire app-data/cashu/ :

cd app-data/cashu

Nous éditons le fichier .env :

nano .env

Ensuite, nous cherchons les paramètres suivants :

# Use with LNbitsWallet
MINT_LNBITS_ENDPOINT=https://yourlnbits.com
MINT_LNBITS_KEY=gds87dskdsjhds71dsdsds2e

Là où il est écrit https://yourlnbits.com, nous mettons https://lnbits.cashu4community.xyz, et là où il est écrit MINT_LNBITS_KEY, nous remplaçons gds87dskdsjhds71dsdsds2e par la clé copiée précédemment 55739ee04e53437aba54fa8c9e4175b8. Le résultat est le suivant :

# Use with LNbitsWallet
MINT_LNBITS_ENDPOINT=https://lnbits.cashu4community.xyz
MINT_LNBITS_KEY=55739ee04e53437aba54fa8c9e4175b8

Nous sauvegardons et quittons le fichier avec ctrl+s et ctrl+x.

Nous redémarrons le conteneur docker-compose restart cashu et les modifications sont appliquées.

6.2 Génération des certificats RPC

Les certificats SSL sont nécessaires pour se connecter au Mint via RPC et exécuter des commandes à distance, utile si nous voulons utiliser Orchard pour administrer le Mint. Pour les générer, nous nous déplaçons dans le répertoire certs de la manière suivante :

cd app-data/cashu/certs

Nous exécutons le script generate_certificates.sh :

./generate_certificates.sh

Ce script générera tous les certificats nécessaires ; nous pouvons le vérifier en exécutant la commande suivante :

ls .
ca_cert.pem  ca_private.pem  client_cert.pem  client_private.pem  generate_certificates.sh  server_cert.pem  server_private.pem

Image 3 : Liste des fichiers dans le répertoire certs.

Après ces modifications, nous redémarrons le conteneur Docker :

docker-compose restart cashu

6.3 Création d'un nouveau keyset depuis la CLI

Nous utiliserons mint-cli pour faire tourner les keysets et définir la commission. Nous procéderons ainsi pour chacune des unités présentes dans le Mint, que ce soit en sats ou en USD.

Pour connaître les unités actives dans le Mint, nous interrogeons le point de terminaison /v1/keysets. Nous le faisons de la manière suivante ; cela peut aussi être fait depuis un navigateur en saisissant l'URL :

curl https://mint.cashu4community.xyz/v1/keysets

La commande curl renvoie ceci :

{
  "keysets": [
    {
      "id": "0145ee812683eaf8ce3859f2601c160d0c8f0d4139447848d0d6745350f3c4fb44",
      "unit": "sat",
      "active": true,
      "input_fee_ppk": 100,
      "final_expiry": null
    }
  ]
}

Ex. : si nous voulions changer le fee de 100 ppk (per-proof-of-knowledge) par sat (Bitcoin) à 50 ppk, nous exécuterions ce qui suit à l'intérieur du conteneur cashu :

docker exec -it app_cashu bash

Une fois dans le conteneur, nous exécutons :

poetry run mint-cli -h cashu next-keyset sat 50
Note : L'argument -h qui accompagne la commande mint-cli est nécessaire car dans un environnement Docker il n'est pas possible d'accéder directement à 127.0.0.1 ; c'est pourquoi nous utilisons cashu, qui est le nom du service déclaré dans le docker compose.

Ce qui renverrait quelque chose comme ceci :

final_expiry = None
New keyset successfully created:
keyset.id = '01e5bac64190f22f2959558b15cbab9f06798958f253a59fbe4687a9d875e3c720'
keyset.unit = 'sat'
keyset.max_order = 64
keyset.input_fee_ppk = 50
0

Si nous exécutons à nouveau la commande :

curl https://mint.cashu4community.xyz/v1/keysets

Elle renvoie la paire de keysets, l'ancien et le nouveau.

{
  "keysets": [
    {
      "id": "0145ee812683eaf8ce3859f2601c160d0c8f0d4139447848d0d6745350f3c4fb44",
      "unit": "sat",
      "active": false,
      "input_fee_ppk": 100,
      "final_expiry": null
    },
    {
      "id": "01e5bac64190f22f2959558b15cbab9f06798958f253a59fbe4687a9d875e3c720",
      "unit": "sat",
      "active": true,
      "input_fee_ppk": 50,
      "final_expiry": null
    }
  ]
}

6.4 Support USD stable avec Blink dans le Mint

La version 0.20.0 de Nutshell a ajouté le support USD via Blink comme source de financement. Les étapes suivantes expliquent ce que nous devons faire aussi bien dans Blink que dans le Mint Cashu.

Comme prérequis, nous devons avoir un compte Blink ; nous pouvons en créer un directement sur https://dashboard.blink.sv sans avoir besoin d'installer l'application. Elle est également disponible pour Android et iOS. Une fois le compte créé, nous accédons au panneau d'administration à la même adresse.

Après la connexion, le panneau d'administration du compte s'affiche, où nous voyons les deux portefeuilles disponibles : un en sats et l'autre en USD, ainsi que plusieurs autres options. Celle qui nous intéresse est API Keys.

Image 4 : Panneau d'administration Blink - API Keys.

  1. Après avoir sélectionné API Keys dans le menu d'options, l'écran suivant apparaît, où nous pourrons créer une nouvelle clé API.

Image 5 : Création d'une nouvelle clé API.

  1. Nous cliquons sur le bouton avec le symbole +.

Une fenêtre apparaît où nous saisirons un nom pour identifier l'utilisation de la clé, la durée de vie de la clé API et les opérations que nous autoriserons avec elle.

Image 6 : Paramètres de la clé API.

  1. Nous saisissons le nom de la clé API, quelque chose qui suggère l'usage qui en sera fait.
  2. Pour la durée d'expiration de la clé, nous sélectionnons Never.
  3. Pour les opérations autorisées avec l'API, nous les sélectionnons toutes.
  4. Nous cliquons sur le bouton Create pour créer la clé.

Après la création de la clé, une fenêtre apparaît une seule fois pour copier les clés API ; il est recommandé de les sauvegarder dans un endroit sûr. Dans notre cas, seule celle liée à l'USD nous intéresse, mais si nous souhaitons utiliser Blink comme compte de financement du Mint aussi bien en USD qu'en BTC, les deux clés seront nécessaires.

Image 7 : Clés API pour se connecter aux comptes BTC et USD de Blink.

  1. Nous copions la clé dans un endroit sûr (c'est celle que nous utiliserons pour connecter le Mint Cashu à Blink).
  2. Nous cliquons sur le bouton Close.

Nous avons ainsi créé la clé qui sera utilisée dans le Mint. Nous revenons au terminal de notre VPS ; nous nous trouvons dans le répertoire cashu4cs-deploy et éditons le fichier .env :

nano app-data/cashu/.env

Dans le fichier, nous cherchons la ligne contenant MINT_DERIVATION_PATH= :

MINT_DERIVATION_PATH="m/0'/0'/0"

Nous nous plaçons au début de la ligne et ajoutons le symbole #, ce qui donne :

# MINT_DERIVATION_PATH="m/0'/0'/0"

Ensuite, nous cherchons la ligne MINT_DERIVATION_PATH_LIST= :

# MINT_DERIVATION_PATH_LIST=["m/0'/0'/0'", "m/0'/0'/1'", "m/0'/1'/0'", "m/0'/2'/0'"]

Nous supprimons le symbole # et les valeurs entre guillemets doubles m/0'/0'/1' et m/0'/1'/0', ce qui donne :

MINT_DERIVATION_PATH_LIST=["m/0'/0'/0'", "m/0'/2'/0'"]
Note : Nous devons faire attention à ne pas supprimer une virgule ni effacer un guillemet, car cela provoquerait une erreur au redémarrage du service Mint.

Maintenant, nous cherchons la ligne MINT_BACKEND_BOLT11_USD=FakeWallet, nous supprimons le symbole # et remplaçons FakeWallet par BlinkWallet, ce qui donne :

MINT_BACKEND_BOLT11_USD=BlinkWallet

Enfin, nous cherchons la connexion à Blink :

# MINT_BLINK_KEY=blink_abcdefgh

Nous supprimons le symbole # et collons la clé créée dans le panneau Blink précédemment. Le résultat ressemble à ceci :

MINT_BLINK_KEY=blink_7Sz978fgdFGjhhT6u8g1tDvruhdeiuyidfdZ1fnDFcPSXKag5uHuip2S1yPP2wHG

Nous sauvegardons et quittons le fichier avec ctrl+s et ctrl+x.

Nous redémarrons le conteneur Docker du Mint Cashu :

docker-compose restart cashu

À partir de ce moment, le Mint est prêt à fonctionner. Nous pourrons envoyer et recevoir des paiements aussi bien en sats qu'en USD depuis des portefeuilles compatibles comme cashu.me, El Caju ou Minibits.
